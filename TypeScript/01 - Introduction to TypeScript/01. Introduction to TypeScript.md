# Introduction to TypeScript

**A Complete TypeScript Course for Beginners**

## Overview

TypeScript is a **superset of JavaScript** that introduces optional static typing and additional features to help developers write more maintainable, reliable, and cleaner code. This lecture provides a high-level overview of TypeScript, its key benefits, and how it compares to JavaScript.

---

## What is TypeScript?

- TypeScript is built on top of JavaScript.
- It includes all JavaScript features, plus additional ones such as:

  - Static type checking
  - Interfaces
  - Access modifiers
  - Decorators

- TypeScript must be compiled to JavaScript because browsers and Node.js cannot run TypeScript directly.

---

## Why Use TypeScript?

- **Improved Code Quality**: Helps catch errors during development instead of at runtime.
- **Strong Typing**: Allows you to specify data types for variables, function parameters, and return values.
- **Better Tooling Support**: Enhanced IntelliSense and autocomplete in editors.
- **Cleaner and More Predictable Code**: Reduces runtime bugs and improves collaboration in large codebases.
- **Modern Features**: Offers new syntax and capabilities not yet available in JavaScript.

---

## TypeScript vs JavaScript

| Feature           | JavaScript                | TypeScript             |
| ----------------- | ------------------------- | ---------------------- |
| Typing            | Dynamic                   | Static (optional)      |
| Type Declarations | Not available             | Available              |
| Compilation       | Not required              | Required (TS → JS)     |
| Runtime Support   | Native in browser/Node.js | Must be compiled to JS |

---

## Example Comparison

**JavaScript:**

```javascript
let val = 100;
val = "string"; // Allowed (dynamic typing)
```

**TypeScript:**

```typescript
let val: number = 100;
val = "string"; // Error: Type 'string' is not assignable to type 'number'
```

**Function Example:**

```typescript
function add(num1: number, num2: number): number {
  return num1 + num2;
}
add(3, 5); // ✅
add("3", "5"); // ❌ Error at compile time
```

---

## Advantages of TypeScript

- **Type Safety**: Catch type-related bugs at compile time.
- **Readable & Maintainable Code**: Code is more structured and easier to debug.
- **Additional Features**: Interfaces, decorators, access modifiers, etc.
- **Highly Configurable Compiler**: Customize compiler behavior for your project.

---

## Disadvantages

- **Compilation Step Required**: TypeScript code must be compiled into JavaScript before execution.
