# Installing & Using TypeScript

## 🧑‍💻 **Overview**

This lecture walks you through **installing TypeScript**, setting up a **basic TypeScript project**, and **compiling TypeScript to JavaScript** using the `tsc` (TypeScript compiler).

---

## ✅ **Why Install TypeScript?**

- Unlike JavaScript, TypeScript **cannot run directly** in the browser or Node.js.
- TypeScript needs to be **compiled to JavaScript** using the **TypeScript compiler (`tsc`)**.

---

## 🔧 **Installation Steps**

### 1. **Install Node.js**

- Visit: [https://nodejs.org](https://nodejs.org)
- Download & install the latest version.
- **Why Node.js?**

  - Node includes **npm (Node Package Manager)**.
  - `npm` is needed to install TypeScript.

### 2. **Check npm Installation**

Open **Command Prompt** (Windows) or **Terminal** (Mac) and type:

```bash
npm -v
```

- If it returns a version number, **npm is installed**.

### 3. **Install TypeScript Globally**

Run this in terminal:

```bash
npm install -g typescript
```

- This installs the **TypeScript compiler (`tsc`)** globally.

---

## 📂 **Project Setup in VS Code**

### 1. **Open VS Code**

- Open a folder (e.g., `typescript-tutorial/typescript-basic`).

### 2. **Create a TypeScript File**

- Create a file: `app.ts`
- Example code:

```ts
console.log("Hello World");
```

---

## 🧪 **Compiling TypeScript Code**

### 1. **Compile Using Terminal**

Navigate to your project folder in terminal:

```bash
cd Desktop/typescript-tutorial/typescript-basic
```

Run:

```bash
tsc app.ts
```

- This generates `app.js`.

### 2. **Link Compiled JS to HTML**

In `index.html`, add:

```html
<script src="app.js"></script>
```

> 💡 Browsers don’t understand `.ts` files, only `.js`.

---

## 🧪 **Testing Output**

- Use **Live Server** extension in VS Code to run the HTML.
- Open **Developer Tools > Console** to see output.

### Example Update:

Change `app.ts` to:

```ts
console.log("This is my first TypeScript code");
```

Then recompile:

```bash
tsc app.ts
```

Refresh the browser to see updated output.
