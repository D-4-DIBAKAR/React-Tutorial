# Data Types in TypeScript

**Topic:** Understanding basic data types in TypeScript — `string`, `number`, and `boolean`.

---

## 📌 Overview

In this lecture, we learn about the three core primitive data types in TypeScript:

- `string`
- `number`
- `boolean`

These types form the foundation of type safety and variable declarations in TypeScript. Additional data types (like `object`, `array`, etc.) are covered in later lectures.

---

## 1. 📄 String Data Type

- A `string` is a sequence of characters.
- Strings can be created using:
  - **Single quotes:** `'This is a string'`
  - **Double quotes:** `"This is also a string"`
  - **Backticks (template literals):** `` `Multiline or embedded values like ${variable}` ``

### 🔹 Benefits of Backticks

- Allow **multi-line strings**
- Enable **template literals** (i.e., embedding expressions inside strings using `${}`)

### 🚫 Limitations with Single/Double Quotes

- Cannot span multiple lines
- Cannot use template expressions (`${}`) like backticks

---

## 2. 🔢 Number Data Type

- TypeScript uses a single `number` type for:
  - Integers: `let num = 12;`
  - Floating-point values: `let pi = 3.14;`
- All numbers in TypeScript (and JavaScript) are stored as **floating-point numbers**, even whole numbers like `12`.

```ts
let num: number = 12;
let pi: number = 3.14;
```

---

## 3. ✅ Boolean Data Type

- The `boolean` type has only two values: `true` and `false`.

```ts
let isEligible: boolean = true;
let isEqual: boolean = false;
```

### 🔹 Truthy and Falsy Values

- **Falsy values** (convert to `false` in Boolean context):

  - `0`
  - `""` (empty string)
  - `null`
  - `undefined`

- **Truthy values** (everything else):

  - Non-zero numbers
  - Non-empty strings
  - Non-null objects

```ts
Boolean(0); // false
Boolean(100); // true
Boolean(""); // false
Boolean("hello"); // true
Boolean(null); // false
```

### 🔍 Boolean from Comparison

Using comparison operators returns a boolean value:

```ts
let isGreater = 10 > 15; // false
let isSmaller = 10 < 15; // true
```
