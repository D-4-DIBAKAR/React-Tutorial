# Variables in TypeScript

### 🎯 **What is a Variable?**

- A variable is a **named storage** used to store values.
- You can **reuse** the variable instead of repeating the value.

---

### 🔑 **Declaring Variables in TypeScript**

- Use `let` or `const` (same as JavaScript).

#### ✅ Using `let`:

```ts
let num = 100; // mutable
```

- You **can declare without initializing**.

```ts
let num;
num = 100;
```

- You **can change the value** later.

#### ✅ Using `const`:

```ts
const str = "Hello World"; // immutable
```

- You **must initialize immediately**.
- You **cannot change the value** later.

```ts
const str = "Hello";
str = "Hi"; // ❌ Error
```

---

### 🧠 **Type Inference**

- TypeScript **infers the type** from the initial value.

```ts
let num = 100; // type: number
```

- Once a type is set, you **cannot assign a different type**.

```ts
num = true; // ❌ Error: boolean not assignable to number
```

- TypeScript is **strongly typed**, unlike JavaScript which is dynamically typed.

---

### 📏 **Rules for Naming Variables**

1. ✅ Only **letters, digits, underscore (\_), and dollar sign (\$)** are allowed.

   - Valid: `first_name`, `$value`, `count1`
   - Invalid: `first-name`, `price%`

2. ❌ **Cannot start with a digit**

   - Invalid: `1name`

3. ✅ Can start with a **letter**, `_`, or `$`

4. 🔠 **Case sensitive**

   - `num` and `Num` are **different** variables.

5. ❌ Cannot use **reserved keywords**

   - Invalid: `let class = 5;`, `if = 10;`

---

### ✅ Summary

- Use `let` for mutable variables, `const` for constants.
- Type is inferred at assignment; cannot change to another type later.
- Follow the variable naming rules to avoid errors.
